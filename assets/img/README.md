# Bilder

Hier gehören die eigenen Fotos hin (Team, Objekte, Vorher/Nachher).

Empfehlung:

- Breite ca. 1600 px, Format WebP oder JPEG, ca. 150–250 KB pro Bild
- sprechende Dateinamen, z. B. `team-treppenhausreinigung.jpg`
- im HTML immer `alt`, `width`, `height` und `loading="lazy"` setzen

Eingebunden werden sie anstelle der farbigen Platzhalterflächen
(`<div class="media">…</div>`), siehe README im Hauptverzeichnis.
